인트로

💬 발화 "7강의 핵심은 하나입니다. AI는 어떤 변수가 수율과 함께 움직이는지 패턴을 보여줍니다.
화면의 LOT 데이터를 보면 PR 점도가 17cp를 넘는 구간에서 수율이 급격히 떨어집니다.
그리고 Coater-2에서만 이 패턴이 반복됩니다.
지금부터 이 패턴이 산점도에서 한눈에 보이는 과정을 보여드리겠습니다."
01:00 – 02:30

Step 1 — 축·색상·강조 조건 없는 막연한 요청

❌ 입력할 프롬프트
PR 점도와 수율 상관관계 분석해줘. lot_id, pr_viscosity_cp, yield_percent, tool_id LOT-001, 14.2, 94, Coater-1 LOT-002, 15.1, 91, Coater-2 ... (이하 동일 데이터)
Claude 응답 예측 — 막연한 프롬프트 입력 시
❌ 막연한 프롬프트 결과

데이터를 확인했습니다. PR 점도와 수율 사이에 음의 상관관계가 보입니다. 분석 전에 몇 가지를 결정해주셔야 합니다.

  • 산점도를 만들까요, 아니면 Pearson/Spearman 상관계수 숫자만 드릴까요?
  • tool_id(Coater-1/2)를 색상으로 구분할까요?
  • 이상 LOT 강조 기준이 있나요? 수율 몇 % 미만을 이상으로 볼까요?
  • 결과에 보고용 문장을 포함할까요?

단순 계산 결과: Pearson r = -0.87 (강한 음의 상관관계). 17cp 이상 구간에서 수율이 낮은 경향이 보입니다.

→ 역질문 4개. 시각화 형태·색상 구분·이상 기준·보고 형식 모두 되물음. 산점도 없음.

💬 발화 (30초) "어떤 축에 무엇을 놓을지, 장비별 색상 구분, 이상 강조 조건, 보고 문장 형식을
말하지 않으면 AI는 선택을 사람에게 돌려보냅니다.
7강에서 배운 4줄 프롬프트가 이것을 한 번에 해결합니다."

브리지 — 4줄 프롬프트 구조 설명

💬 발화 "7강 4줄 프롬프트 구조입니다.
1줄 — 어떤 관계를 어떤 차트로: 'PR 점도와 수율의 상관관계를 산점도로'
2줄 — 축·색상·강조 조건: 'x축=점도, y축=수율, 색상=장비, 90% 미만 빨강'
3줄 — 해석 지시: '방향·이상치·장비 군집 차이 설명 + 원인 후보 3개'
4줄 — 결과 형식: '표, 그래프 설명, 보고 초안 순서로'
지금 이 네 줄을 모두 담아서 입력하겠습니다."

Step 3 — Coater-2 단독 필터링 산점도 추가

마무리 — 핵심 메시지

핵심 3가지

1️⃣

축·색상·강조 조건·보고 형식을 말하지 않으면 AI는 상관계수 숫자만 주고 나머지를 되물어봅니다.

2️⃣

4줄 프롬프트로 산점도 + 추세선 + 이상 LOT 강조 + 보고 초안 3문장이 한 번에 나옵니다.

3️⃣

AI가 찾은 "17cp 이상 Coater-2 집중" 패턴이 점도 공급 불안정인지 장비 헤드 마모인지 확정하는 것은 엔지니어가 PM 이력과 대조해서 합니다.

"AI는 패턴을 보여줍니다.
원인을 확정하는 것은 엔지니어입니다."
