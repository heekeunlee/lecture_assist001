❌ 일반 프롬프트 결과

데이터를 확인했습니다. 분석을 진행하기 전에 몇 가지 확인이 필요합니다.

  • "낮은 날"의 기준이 어떻게 되나요? (예: 94% 미만, 평균 이하, 전일 대비 하락 등)
  • 메일 수신자가 파트장님이시면 공식 형식으로 작성할까요, 아니면 간단한 요약 형식으로 드릴까요?
  • 조치 권고 문구도 포함할까요?

일단 간단하게 정리해드릴게요:

전체 7일 중 평균(94.0%) 이하로 보이는 날은 04-24(93.1%), 04-25(91.8%), 04-26(92.6%)입니다. 파트장님께 보고할 메일을 작성해드릴까요?

→ 역질문 3개 + 기준 없는 단순 텍스트 요약. 색상 표·그래프·조치권고·메일 형식 없음.

'낮다'의 기준, 메일 형식, 조치 권고 포함 여부를 말하지 않으면
원하는 결과가 나오지 않습니다."

브리지 — TCREI + Pseudo-Prompt 30초 소개

💬 발화 "2강에서 배운 두 가지 도구를 지금 바로 써보겠습니다.
TCREI — Role(역할)·Context(맥락)·Task(할 일)·Exemplar(형식)·Input(데이터).
Pseudo-Prompt — SETTING(기준값), STEP(단계), 조건(IF)으로 로직을 설계합니다.
코드 한 줄 없이, 설계도처럼 AI에게 지시하는 방식입니다."
T — Task
수율 94% 미만 필터 → HTML 메일 초안 생성
C — Context
신규 라인 안정화 단계, 파트장 즉시 보고 필요
R — Role
15년차 공정 데이터 분석 전문 엔지니어
E — Exemplar
색상 표 + 꺾은선 + 조치권고 포함 공식 HTML 메일
I — Input
04-22~04-28 공정별 수율(%) 데이터 7행
03:30 – 07:00

Step 2 — TCREI + Pseudo-Prompt 완성형 입력

✅ 입력할 프롬프트 (그대로 복사 · 붙여넣기)
[ROLE] 너는 15년차 반도체 공정 데이터 분석 전문 엔지니어야. 공정 이상 구간을 빠르게 식별하고 실무자용 보고서를 작성하는 게 특기야. [CONTEXT] 신규 라인 안정화 단계에서 수율이 기준치를 밑도는 날이 발생했어. 품질혁신 파트장님께 즉시 보고해야 해. [SETTING] TARGET_YIELD = 94.0% REPORT_RECIPIENT = '품질혁신 파트장' [INPUT - 수율 데이터] 날짜, 공정, 수율(%) 04-22, Photo, 95.3 04-23, Photo, 94.8 04-24, Photo, 93.1 04-25, Etch, 91.8 04-26, Array, 92.6 04-27, Array, 95.1 04-28, Etch, 95.4 [STEP 1] 데이터를 날짜 순으로 정렬한다. [STEP 2] 수율이 TARGET_YIELD(94.0%) 미만인 행만 필터링한다. [STEP 3] 필터링된 행에서 [날짜, 공정, 수율, 전일대비 차이, 조치권고]를 계산한다. - 전일 대비 -2% 이상 하락 → '긴급 점검' - 전일 대비 -1~2% 하락 → '모니터링' [STEP 4] 전체 7일 수율 추이를 꺾은선 그래프 (SVG)로 만든다. 94% 기준선을 빨간 점선으로 표시한다. [STEP 5] 위 결과를 REPORT_RECIPIENT에게 보내는 HTML 메일 초안으로 만든다. - 수율 미달 행은 빨간색, 정상 행은 흰색으로 표시 - 메일 제목: "4월 4주차 수율 이상 보고 — 즉시 확인 요청" - 하단에 엔지니어 현장 확인 체크리스트 3항목 포함 [TASK] 위 STEP 1~5를 순서대로 실행해서 완성된 HTML 메일 보고서를 출력해줘.
💬 발화 — 결과 생성 대기 중 (30초) "Role로 역할을 줬고, SETTING으로 기준값을 명시했고,
STEP으로 분석 순서를 설계도처럼 지시했습니다.
AI가 역질문 없이 바로 실행합니다."

마무리 — 핵심 메시지

💬 발화 "오늘 시연에서 세 가지를 확인했습니다."

핵심 3가지

1️⃣

일반 프롬프트는 기준이 없어 AI가 역질문합니다. 데이터가 있어도 마찬가지입니다.

2️⃣

TCREI + Pseudo-Prompt는 역할·맥락·기준값·단계를 모두 지정합니다.
AI가 역질문 없이 HTML 메일 보고서를 한 번에 만듭니다.

3️⃣

변수(TARGET_YIELD) 하나만 바꾸면 전체 보고서 기준이 즉시 바뀝니다.
설계도를 한 번 만들면 다음부터는 숫자만 수정하면 됩니다.

"프롬프트 설계는 엔지니어의 새로운 설계도입니다."
