SECTION 01

오늘의 분석 시나리오

상황

Photo 공정 이후 특정 LOT의 수율이 하락했어요. PR 점도, 노광 dose, 현상 시간, 검사 불량률 중 어떤 변수가 먼저 의심되는지 빠르게 확인해야 해요.

핵심 질문

"어떤 공정 변수가 수율 또는 불량률과 함께 움직이는가?"를 먼저 묻습니다. 산점도는 이 질문에 가장 빠르게 답하는 기본 시각화예요.

최종 산출물

원본 데이터 표 → 산점도 2개 (PR 점도 vs 수율, 식각 압력 vs 불량률) → AI 보고 초안 3문장. 숫자 표가 판단 가능한 리포트로 바뀌어요.

SECTION 03

산점도로 관계 읽기

산점도 2종 — PR 점도 vs 수율 / 식각 압력 vs 불량률

① PR 점도 (cp) vs 수율 (%)

음의 상관관계. PR 점도 17cp 이상 구간에서 수율 하락 LOT 집중. Coater-2(빨간점) 편향.

② 식각 압력 vs 불량률 (%)

양의 상관관계. 식각 압력 상승 시 불량률 증가. Etch 공정 보조 확인 대상.

두 산점도를 같이 보면 — Photo 공정의 PR 점도 문제가 더 직접적인 원인 후보이고, Etch는 보조 확인 대상이에요.

SECTION 04

정상/이상 패턴 구분

산점도 패턴 3가지

정상 변동

점들이 넓게 퍼지지만 방향이 약함

수율이 작은 범위 안에서 흔들리고 특정 변수와 뚜렷한 방향성이 없다면 공정 노이즈나 자연 변동일 수 있어요.

강한 상관

점들이 한 방향으로 기울어짐

PR 점도 ↑ → 수율 ↓ 처럼 방향성이 보이면 해당 변수를 우선 확인 후보로 둬요.

이상 군집

특정 장비/LOT만 따로 모임

전체 추세와 다르게 특정 장비, recipe, shift 데이터가 분리되면 단일 변수보다 조합 조건을 확인해야 해요.

산점도 4가지 체크포인트

확인 항목그래프에서 보는 것엔지니어 판단
점의 방향우상향, 우하향, 방향 없음변수가 결과와 함께 움직이는지 확인
점의 밀집도넓게 퍼짐 또는 좁게 몰림공정 변동이 안정적인지 확인
이상치혼자 튄 점 또는 작은 묶음특정 LOT, 장비, recipe 이력 확인
군집 분리색상별로 다른 영역 형성교대조, 장비, 자재 LOT 같은 숨은 조건 확인

⚠️ 산점도 패턴은 원인을 확정하지 않아요. 원인 후보를 좁혀줘요. 최종 판단은 엔지니어가 현장 지식과 이력을 가지고 해요.

SECTION 05

AI 실습 — 산점도 + 보고 초안

실습 3단계

STEP 1

원본 표를 설명한다

컬럼 의미, 단위, 정상 기준, 확인하려는 결과값을 먼저 알려줘요. AI가 컬럼명을 추측하지 않게 해야 해요.

STEP 2

산점도 요구사항을 지정한다

x축, y축, 색상 기준, 이상치 강조 기준을 명확히 말해요. 실제 CSV 컬럼명을 그대로 써야 해요.

STEP 3

해석과 보고 문장을 요구한다

그래프만 아니라 관찰 패턴, 원인 후보, 추가 확인 데이터, 보고용 3문장을 함께 출력하도록 지시해요.

4줄 AI 프롬프트

1. Photo 공정 데이터에서 PR 점도와 수율의 상관관계를 산점도로 시각화해줘. 2. x축은 pr_viscosity_cp, y축은 yield_percent, 색상은 tool_id로 구분하고 수율 90% 미만 LOT은 빨간색으로 강조해줘. 3. 점의 방향, 이상치, 장비별 군집 차이를 설명하고 원인 후보 3개와 추가 확인 항목 2개를 정리해줘. 4. 결과는 표, 그래프 설명, 보고 초안 순서로 구성해줘.

2번 줄이 중요해요 — pr_viscosity_cp, yield_percent, tool_id — 실제 CSV 컬럼명을 그대로 써야 AI가 바로 실행해요.

AI 보고 초안 예시

AI가 생성한 보고 3문장

1 PR 점도 17cp 이상 구간에서 수율 하락 LOT가 집중되어 점도 조건이 우선 확인 변수로 보입니다.
2 이상 LOT는 Coater-2 장비에서 주로 발생했으므로 점도 자체와 장비 조건을 분리해 비교해야 합니다.
3 다음 분석은 같은 recipe의 최근 3주 LOT, 장비 PM 이력, 노광 dose 변동을 함께 연결해 확인하는 것이 적절합니다.

AI가 결론을 단정한 게 아니에요. 관찰 사실을 정리한 거예요. "17cp 이상 구간 집중", "Coater-2 편향" — 패턴이에요. "점도 자체와 장비 조건을 분리해 비교" — 다음 분석 방향 제안이에요. 최종 판단은 엔지니어가 해요.

핵심 메시지
"AI는 관찰 사실을 정리하고,
판단은 엔지니어가 합니다."

    산점도는 방향·이상치·군집 세 가지를 봐요 — 이 세 가지만 확인해도 원인 후보 방향이 5분 안에 나와요.
  • ✓
    AI에게 컬럼명·x축·y축·색상 기준을 명확히 지시해요 — "산점도 그려줘"만으로는 부족해요. 실제 컬럼명을 써야 해요.
  • ✓
    AI 보고 초안은 관찰 사실이에요 — 원인을 단정하지 않아요. 엔지니어가 현장 지식과 맞는지 검토해야 해요.
