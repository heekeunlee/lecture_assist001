그 다음 질문이에요. "여러 불량 중에서, 지금 무엇부터 먼저 조치해야 하는가?"

SECTION 01

실무 판단 4가지 기준

건수 1위 ≠ 조치 1순위

빈도

얼마나 많이 발생했는가?

유형별 건수, 점유율, 누적 기여율로 전체 손실의 큰 덩어리를 찾아요.

영향도

수율과 비용을 얼마나 깎는가?

심각도, 패널 폐기 여부, 재작업 비용을 반영해 단순 건수와 손실 순위를 분리해요.

변화율

최근에 얼마나 빠르게 커지는가?

최근 4주와 기준 4주를 비교해 누적 상위와 급증 항목을 따로 봐요.

난이도

지금 바로 확인할 수 있는가?

설비 정지나 장기 실험이 필요한 항목과 즉시 점검 가능한 항목을 나눠요.

판단 질문 — "이 불량이 1위입니다"에서 멈추지 말고, "왜 이 불량을 먼저 봐야 하는지"를 수치와 확인 데이터로 설명할 수 있어야 해요.

SECTION 02

파레토 개념 + 계산식

3가지 분석 기준

개수 기준

가장 많이 발생한 불량

검사 로그에서 유형별 빈도를 집계해요. 현장 회의의 출발점으로 좋아요.

영향 기준

수율을 가장 많이 깎는 불량

건수에 심각도·폐기 여부·재작업 비용을 곱해 실제 손실 기여도를 봐요.

변화 기준

최근 급격히 커지는 불량

누적 상위가 아니어도 최근 2~4주 상승률이 크면 선제 조치 대상이 돼요.

계산식

불량 점유율 = 유형별 불량 수 / 전체 불량 수 × 100
누적 기여율 = 상위 유형부터 점유율을 순서대로 더한 값
트렌드 변화율 = 최근 기간 평균 / 기준 기간 평균 − 1

// 누적 기여율 80%를 만드는 상위 불량 유형 → 핵심 관리 대상
// 트렌드 변화율 +20% 이상 → 급증 불량 선제 조치 대상

⚠️ 흔한 오해 — "상위 80%만 보면 나머지는 무시해도 된다"는 뜻이 아니에요. 하위 항목 안에도 폐기율이 높은 불량이 있을 수 있어요. 영향도와 변화율을 반드시 함께 봐야 해요.

AI 프롬프트 3종

① 파레토 차트 생성

내가 제공한 defect_log.csv 데이터를 기반으로 파레토 차트를 그려줘. 1. X축은 '불량 유형', Y축 좌측은 '발생 건수' 막대그래프, Y축 우측은 '누적 점유율(%)' 꺾은선으로 이중 축 설정. 2. 누적 점유율이 80%가 되는 지점에 붉은색 수평 점선을 그어 줘. 3. 80% 이내에 속하는 불량 유형들은 '핵심 관리 대상'으로 막대 색상을 진하게 표시해 줘.

② 트렌드 차트 생성

주차별 주요 불량의 발생 건수 추이를 꺾은선 차트로 그려줘. 1. 전체 불량이 아닌 누적 상위 5개 불량 유형만 필터링해서 보여줄 것. 2. 각 선의 끝(가장 최근 주차)에 불량 유형 라벨과 건수를 직접 표기. 범례 최소화. 3. 4주 전 대비 증가율이 20% 이상인 불량은 꺾은선을 붉은색 굵은 선으로 강조해 줘.

③ 액션 매트릭스 생성

불량 유형들을 4분면 액션 매트릭스에 배치해 줘. 1. X축은 '조치 난이도 및 예상 소요 시간', Y축은 '수율 영향도 및 손실 비용'. 2. 점의 크기는 '발생 건수'에 비례하게 설정 (버블 차트). 3. 좌측 상단 2사분면 (영향도 높고 난이도 낮음)의 배경을 옅은 녹색으로 칠하고 'Quick Wins 우선 조치' 라벨을 달아 줘.
SECTION 04

Bump Chart — 순위 역전 포착

4주간 불량 순위 변동

CD Drift가 4주 만에 4위 → 1위로 급상승 — 최우선 조치 대상으로 부상. 파레토 차트만 보면 놓치는 정보.

순위 유지

고질적 불량 요인

항상 상위권을 유지하는 불량. 근본적인 공정 개선이나 설비 개조가 필요한 장기 과제예요.

순위 상승

신규 돌발성 요인

갑자기 급상승하는 불량. 최근 변경된 작업자, 자재, 파츠 수명 등을 즉각 확인해야 해요.

순위 하락

개선 효과 검증

최근 진행한 개선 대책이 실제로 효과가 있었는지 검증하는 지표예요.

SECTION 05

AI 파이프라인 + 작업지시서

나쁜 지시문 vs 좋은 지시문

나쁜 지시문

defect_log.csv 분석해서 파레토 차트 그려줘.

컬럼, 기간, 결측 처리, 중복 기준, 산출물 형식이 없어서 AI가 임의로 가정해요.
좋은 지시문

최근 4주와 이전 4주 평균을 비교하고, 결측/중복을 경고하며, 상위 80%와 급증 Top 3를 분리해 보고서 문장으로 작성해라.

분석 기준, 검증 기준, 결과 형식이 명확해서 회의 자료로 바로 쓸 수 있어요.

AI 5블록 지시서

역할

너는 디스플레이 제조 데이터 분석을 돕는 공정 엔지니어링 분석가다.

입력 데이터

컬럼: date, line, process, panel_id, defect_type, x, y, severity, lot_id. 결측치와 이상값은 따로 표시해라.

분석 작업

불량 유형별 파레토, 주차별 트렌드, 라인별 편차, 최근 4주 급증 유형을 계산하고 표와 차트로 요약해라.

검증 기준

총 불량 수 합계가 원본 행 수와 맞는지 확인하고, 상위 80%를 만드는 유형을 별도로 표시해라.

산출물

우선 조치 3개, 원인 가설, 필요한 추가 데이터, 다음 실험 계획을 엔지니어 보고서 문장으로 작성해라.

5블록이 다 있어야 AI가 임의 가정 없이 작업해요. 역할 → 입력 데이터 → 분석 작업 → 검증 기준 → 산출물.

실습 작업지시서

내가 가진 defect_log.csv를 분석하는 웹 도구를 만들어줘. 필수 기능: 1. CSV 업로드 후 defect_type, date, line, process 기준으로 집계 2. 불량 유형별 파레토 차트와 누적 80% 기준선 표시 3. 주차별 Top 3 불량 트렌드 라인 차트 표시 4. 최근 4주 증가율이 큰 불량을 별도 카드로 표시 5. severity를 반영한 손실 점수 파레토를 옵션으로 표시 6. 우선 조치 후보 3개를 '불량명 / 근거 / 확인할 데이터 / 다음 실험' 형식으로 출력 검증: - 전체 행 수와 집계 합계가 맞는지 표시 - 결측 defect_type, 잘못된 date, 중복 panel_id를 경고 - 원본 행 수, 제외 행 수, 분석 사용 행 수를 각각 표시 - 차트 아래에 엔지니어가 해석할 수 있는 3문장 요약 제공
입력
defect_log.csv

검사일, 라인, 공정, 패널 ID, 불량 유형, 좌표, 심각도

처리
집계 + 정렬 + 변화율

유형별 빈도, 누적 기여율, 주차별 Top 3 추세

출력
우선 조치 리포트

상위 불량, 급증 불량, 확인 로그, 다음 실험 계획

검증 체크리스트 + 마무리

AI 결과 사용 전 검증 7가지

  • 1
    불량명 표기가 Particle, particle, PRT처럼 섞여 있지 않은가?
  • 2
    동일 패널의 중복 카운트 기준이 명확한가?
  • 3
    검사일, 공정 투입일, lot 종료일 중 어떤 날짜 기준으로 트렌드를 집계했는가? (자주 헷갈리는 항목)
  • 4
    개수 기준과 수율 영향도 기준을 혼동하지 않았는가?
  • 5
    최근 급증한 불량과 누적 상위 불량을 따로 해석했는가?
  • 6
    AI가 만든 원인 가설을 설비 로그, recipe 변경 이력, LOT 이력으로 검증했는가?
  • 7
    차트의 단위와 보고서 문장의 단위가 defect count인지 panel count인지 일치하는가? (자주 헷갈리는 항목)
