SECTION 02 · 왜 데이터 정제인가?

예상 시간: 5:00 ~ 15:00 (10분)

↓ 스크롤

AI가 잘못된 데이터를 받으면 엉뚱한 답을 내놓아요.

"Garbage In, Garbage Out." 데이터를 AI에게 넘기기 전에 오염 여부를 확인하지 않으면 — 이상 감지 알람은 거짓 경보로 가득 차고, 수율 예측 모델의 정확도는 현장에서 쓸 수 없는 수준으로 떨어져요.

⏸ 잠깐

"CVD 온도 데이터를 그대로 분석에 썼더니 수율 예측 R²가 0.62였습니다. 결측·이상치·노이즈를 정제하고 나니 동일 모델이 R² 0.89로 올라갔습니다. 데이터 정제가 모델 개발보다 수율에 더 직접적인 영향을 줬습니다."

같은 모델이에요. 코드를 바꾼 게 아니에요. 데이터만 정제했더니 R²가 0.62에서 0.89로 올라간 거예요. 데이터 정제는 전처리가 아니에요. AI를 현장 도구로 만드는 출발점이에요.

SECTION 04 · 정제 알고리즘

예상 시간: 20:00 ~ 32:00 (12분)

↓ 스크롤

상황에 맞는 알고리즘 선택이 핵심이에요. 모든 데이터 오염에 통하는 하나의 정제 방법은 없어요. 결측 구간 길이, 데이터 분포, 공정의 물리적 의미에 따라 올바른 방법을 선택해야 해요.

⏸ 잠깐

첫 번째 — Z-score 이상치 탐지.

Z = (x - μ) / σ → |Z| > 3 이면 이상치

각 데이터 포인트가 평균에서 표준편차의 몇 배나 떨어져 있는지를 계산해요. 3배 이상이면 이상치로 판정하는 거예요.

214.5°C 예시: 앞뒤 평균 77°C, 표준편차 1.5°C라면 Z = (214.5 - 77) / 1.5 = 91.7. 명백한 이상치예요.

장점: 계산이 단순하고 해석이 직관적. 정규분포 데이터에서 높은 정확도.

주의: 비정규 분포에서는 오판정 가능. 이상치 자체가 평균·표준편차를 왜곡할 수 있어요.

추천 적용: 반도체 CVD 온도, 디스플레이 증착 두께처럼 정규분포에 가까운 공정 파라미터.

⏸ 잠깐

두 번째 — IQR 방법, 사분범위.

IQR = Q3 - Q1 이상치: x < Q1 - 1.5×IQR 또는 x > Q3 + 1.5×IQR

데이터를 정렬했을 때 하위 25% 지점이 Q1, 상위 25% 지점이 Q3이에요. 그 사이 범위가 IQR. Z-score는 정규분포 가정이 있지만, IQR은 분포 가정이 없는 비모수적 방법이에요.

장점: 분포 가정 불필요, 극단값에 강건하고 배치 처리에 적합.

주의: 소규모 데이터셋에서 과도한 탐지 가능.

추천 적용: 2차전지 전압·전류처럼 분포가 불규칙하거나 공정 단계별로 분포가 바뀌는 데이터.

⏸ 잠깐

세 번째 — 이동평균 스무딩.

MA(t) = (x[t-n+1] + ... + x[t]) / n (보통 n = 5~20 사용)

연속된 n개 값의 평균으로 현재 시점 값을 대체하는 거예요. 윈도우 n이 클수록 더 부드러워지지만 반응 속도가 느려져요. 노이즈 제거와 이상치 교체에 모두 쓸 수 있어요.

주의: 급격한 공정 변화 구간에서는 실제 신호까지 평활화될 수 있어요.

추천 적용: 설비 온도·압력·유량처럼 완만하게 변화하는 연속형 센서 데이터의 노이즈 제거.

⏸ 잠깐

네 번째 — 선형 보간, 결측치 처리.

x(t) = x(t₁) + [x(t₂) - x(t₁)] × (t - t₁) / (t₂ - t₁)

결측 구간 양쪽의 알려진 값을 직선으로 연결해 빠진 값을 추정해요. 09:10 NaN이 77.0°C로 채워진 게 이 방식이에요. 76.8°C(09:05)와 77.4°C(09:25) 사이를 직선으로 이어서 값을 메운 거예요.

주의: 결측 구간이 길어질수록 실제 공정과 괴리가 커져요.

추천 적용: 통신 단절로 짧게 누락된 CVD·PVD 공정 파라미터 복원. 5분 이내 결측에 권장.
